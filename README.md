# 项目资料台

把本地文件夹、项目计划和随手笔记放在一起的个人工作工具。

**2.1.0 · Windows x64 免安装体验版 · 2026-10-28**

按原来的文件夹找资料，搜索文档里的关键词，把需要的内容记进笔记，再看每个项目接下来要做什么。

## 三步开始

1. 打开本仓库的 **Releases**，下载 `project-desk-2.1.0-windows-x64.zip`。
2. 将 ZIP **完整解压**到自己有写入权限的文件夹，双击 `启动项目资料台.cmd`。
3. 选择自己的资料文件夹，或点击“先建空白计划”。资料台会在默认浏览器中打开。

包内含运行环境，无需安装 Codex、Node.js、Python 或 Office。预览不支持的文件仍需电脑有对应软件才能打开原文件。普通使用者不需要下载源码包。

项目、待办和笔记均从空白开始，不包含作者的客户、项目或资料。已有文件夹保持原来的组织方式，也可以先建计划，之后再关联资料。

## 日常工作

| 板块 | 用途 |
| --- | --- |
| 项目进度 | 添加项目与节点，键盘输入计划和完成日期，关联资料；拖动项目调整优先级，关闭或恢复项目；集中查看“下一个节点”。 |
| 全部待办 | 汇总需要跟进的事项，安排日常工作。 |
| 找资料 | 按多级文件夹浏览缩略图，用文件时间线正序或倒序找文件；顶部搜索查文件名、标签及支持格式的正文。 |
| 记录库 | 瀑布流笔记卡片，点击放大编辑；支持标签、置顶、拖拽排序，可关联多个源文件。 |

### 从资料到笔记

- 在搜索结果中“记下来”，保存摘录并关联来源。
- 在 Excel 预览中点“多选”，逐个选中所需单元格；也可用 Ctrl 多选、Shift 连选或鼠标拖选，一次记入笔记。可新建，也可追加到已有笔记。
- 在 Word 预览中选中文字，再点击“记入笔记”。
- 笔记的来源入口可以重新打开文件；源文件更新或暂不可用时，已保存的摘录仍保留，不会自动随原文改写。
- 置顶笔记和普通笔记分别排序；搜索笔记时先清空搜索，再拖动调整顺序。

### 保留文件夹习惯

资料台监听选定目录的变化，新增文件后更新索引。查看资料不改写原文件。将文件拖入目标目录时，经确认保存副本，同名文件自动改名以避免覆盖。

微信直拖能否成功取决于微信是否提供可读取的文件数据；不成功时先下载或另存为，再拖入。

## 支持范围

| 格式 | 正文检索 | 预览 |
| --- | --- | --- |
| Word `.docx` | 可提取文字 | 页面、表格、图片和文字，可缩放和摘录；补充编号、缩进、行距及部分旧式图形的兼容处理。 |
| Excel `.xlsx`、`.xlsm` | 单元格文字 | 按列宽、行高和合并单元格展示，支持工作表切换、缩放与多选摘录。 |
| PowerPoint `.pptx`、`.pptm` | 可提取文字 | 不提供完整幻灯片版式预览，可打开原文件。 |
| PDF | 已有文字层 | 浏览器内预览。扫描图片没有文字层时无法正文检索。 |
| TXT、Markdown、CSV、TSV | 支持 | 文本内容预览。 |
| 旧版 `.doc`、`.xls`、`.ppt` | 取决于电脑已有的 Windows 文档筛选器 | 调用对应软件打开原文件；无法检索时可另存为新版格式。 |
| 图片、视频、音频 | 可查文件名、路径等信息，不识别其中的文字或音视频内容 | 常见图片及浏览器能够解码的媒体。 |
| STP/STEP 等 CAD 文件 | 可查文件名、路径等信息，不解析模型尺寸 | 使用电脑已有软件打开原文件。 |

正文索引在本机建立，首次连接大量资料时需要等待。搜索结果只显示关键词附近的短片段，完整内容可进入预览查看。索引状态会提示未完成、无法提取或仅部分索引的文件。

复杂 Office 文档的分页、字体、图表和特殊对象可能与原软件不同。Excel 不重算公式、不运行宏；Word 不保证逐像素还原原软件。扫描件 OCR、内嵌 CAD 查看器尚未提供。

## 停止、切换与备份

**不用时点击右上角“停止运行”。** 仅关闭浏览器不会主动停止后台服务。下次继续双击启动文件；本机端口可能变化，请勿收藏某个固定端口的网页地址。

切换资料范围：先停止运行，再双击 `切换资料目录.cmd`。不同目录对应独立工作区，计划、待办、文件备注和笔记分别保存；切回原目录可继续原来的工作。“先建空白计划”使用程序包内的 `资料` 文件夹。

备份前先停止运行，保留：

- `data/`：包含工作区数据、索引和缓存，计划及笔记在工作区目录内。
- `settings.json`：资料目录与工作区配置。
- 自己的原始资料文件夹：请另行备份，程序不会自动把原件复制进备份。

可移动整个解压目录，但外部资料路径仍须有效。不要只移动启动文件，不要删除 `app/`、`runtime/` 或使用中的数据。

新版解压到新目录可以独立体验，不会自动迁移旧版计划和笔记。先保留旧包与备份，不要直接覆盖删除。

## 当前边界与排查

服务只监听本机回环地址，文档读取、预览和索引在本机完成。没有安卓 APK、云端同步、远程访问或多人协作；笔记中的来源链接也不会把原文件分享给别人。

这是体验版本，跨电脑实际兼容性仍需继续验证。公司电脑若限制脚本或可执行文件，请按所在组织规定处理。优先接入具体的资料文件夹，避免整个磁盘或软件安装目录。

- **启动失败：** 确认完整解压且目录可写；启动窗口会保留报错，可查看 `data/server-error.log`。
- **目录选择窗口打不开：** 先双击 `直接建立空白工作区.cmd`，需要时再停止运行并切换目录；错误记录在 `data/folder-picker-error.log`。
- **页面连接失败：** 重新双击启动文件，不要继续使用以前的网页地址。
- **搜不到正文：** 等待索引完成并查看检索提示；扫描件、加密文档、无法解析的旧格式或超过读取限制的内容可能无法完整检索。
- **版式仍有差异：** 用“打开原文件”核对。反馈时提供格式、系统版本与脱敏截图，避免上传私人原件或整份 `data/`。

## 源码与构建

`project-desk-2.1.0-source.zip` 包含整理后的源码，不含运行时和个人工作区数据；它不是可直接双击运行的完整体验包。

```text
app/                    应用源码、网页资源与便携启动入口
tools/build-windows.py  Windows 发布包构建脚本
requirements-build.txt Python 构建依赖
licenses/              随附第三方许可
start.ps1              启动脚本
*.cmd                  启动、空白工作区与切换目录入口
```

维护者在 Windows x64 上准备 Node.js 24 x64、Python 3.12 x64，并在该 Python 中安装 `requirements-build.txt` 后，运行：

```powershell
python tools/build-windows.py --node "C:\Tools\node\node.exe" --python-home "C:\Tools\Python312" --output "C:\Build\project-desk-2.1.0"
```

示例路径请替换为自己的实际位置，输出应选择尚不存在的新目录。运行时和构建产物不进入源码仓库。

## 上传 GitHub

1. 解压源码包，将其中的仓库内容上传到 GitHub；不要上传个人正在使用的程序目录。
2. 创建 `v2.1.0` Release，填写本版更新说明。
3. 将 `project-desk-2.1.0-windows-x64.zip`、对应 SHA-256 校验文件及需要提供的源码包作为 Release 附件。

操作参考：[向仓库添加文件](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)、[GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)。

对外分享请使用最初生成的干净 ZIP。不要重新打包已经使用过的文件夹，其中可能含资料路径、笔记、日志和缩略图。

主项目目前未声明开源许可证；公开源码不等于自动授予额外授权。第三方组件按各自许可证分发，许可文件见 `licenses/`、`app/public/vendor/` 和运行时的组件目录，请随包保留。
